# Một năm bên nhau ♡

## Mở trong VS Code
1. Giải nén anniversary-website.zip.
2. VS Code → File → Open Folder → chọn thư mục anniversary-website.
3. Mở index.html để chỉnh sửa. CSS nằm trong thẻ <style>, JavaScript nằm trong thẻ <script>.
4. Nhấp đúp index.html để xem bằng trình duyệt, hoặc dùng tiện ích Live Server trong VS Code.

Không cần npm hay cài thư viện. Thư mục images chứa 5 ảnh minh họa.
Font Google cần Internet; khi offline trang dùng font dự phòng.

## Cá nhân hóa
- Sửa tiêu đề, nội dung, đường dẫn ảnh trực tiếp trong index.html để mọi người đều thấy khi bạn đăng lại website.
- Có thể dùng nút Cá nhân hóa trên trang; thay đổi này chỉ lưu trên trình duyệt đang dùng.
- Ảnh đã chọn trên trang đang online không tự chuyển vào bản tải về.
- Các chỉ số 01 năm / 12 tháng / 365 ngày là nội dung kỷ niệm cố định, không phải bộ đếm thời gian thực.
- Bật giai điệu để nghe nhạc nền tổng hợp bằng Web Audio.

Bản này là bản sao để sửa trên máy. Chỉnh sửa trong VS Code không tự cập nhật website đã công khai.
